## About me

Software Engineering student and full-stack builder focused on shipping **complete products** — authentication, roles, APIs, dashboards, and demos that work in production.

I design systems for **student communities and tech clubs**: tournament platforms, attendance tools, contributor workflows, and logistics apps. My goal is simple — clean architecture, reliable APIs, and interfaces non-developers can actually use.

| | |
|:--|:--|
| **What I build** | Contest platforms · club portals · contributor systems · tracking tools |
| **How I build** | React / Next.js · Node / Express · MongoDB / Postgres · Socket.IO · Flutter |
| **What I care about** | JWT + RBAC · clear APIs · usable dashboards · real users |

### Currently shipping

- **[TemariHub Contributor](https://temarihub-contributer.vercel.app)** — multi-phase contributor workflow (auth → jobs → templates → review → export → notifications)
- **[Code Arena 2026](https://code-arena-weld.vercel.app)** — tournament platform with groups, playoffs, and live **Codeforces** sync
- Active across **NCC**, **CSEC**, and **INSA** challenges
